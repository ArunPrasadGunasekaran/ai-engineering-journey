# Week 1 - Python Fundamentals

This repository contains my Week 1 Python learning journey as part of my transition toward becoming an AI Engineer.

The focus of this week was to build a strong foundation in Python programming and practice writing small programs from scratch.

## 🎯 Week 1 Goals

- Understand Python syntax and basic programming concepts
- Practice variables and data types
- Work with user input and output
- Understand conditional statements
- Practice loops
- Work with Lists, Tuples, Sets and Dictionaries
- Understand functions
- Practice list comprehensions
- Solve small programming problems
- Build confidence in writing Python without relying heavily on external solutions

## 📚 Topics Covered

### 1. Python Basics
- Variables
- Data types
- Type conversion
- Input and output
- Basic operators

### 2. Conditional Statements
- `if`
- `elif`
- `else`
- Comparison operators
- Logical operators

### 3. Loops
- `for` loops
- `while` loops
- Loop control
- `break`
- `continue`

### 4. Python Collections
- Lists
- Tuples
- Sets
- Dictionaries
- Adding, updating and accessing collection elements
- Iterating through collections

### 5. Functions
- Defining functions
- Parameters and arguments
- Return values
- Reusing functions to avoid duplicate code

### 6. List Comprehension
- Creating lists using comprehensions
- Applying conditions inside comprehensions
- Writing more concise Python code
